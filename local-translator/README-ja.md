# Kotoba Client ローカル翻訳（Windows）

このフォルダーは外部翻訳 API の代わりに、Argos Translate の英日モデルをこの PC で動かす補助ツールです。翻訳データはチャット運営者などの外部 API へ送らず、`127.0.0.1`（この PC 内）だけで処理します。

## 最初の一度だけ

1. Python 3.11 がない場合、`1-Setup-Local-Translator.bat` を実行します。案内ページで Python 3.11 をインストールし、もう一度このファイルを実行してください。
2. セットアップが英日モデル（約115MB）と必要な Python 部品をダウンロードします。完了までネット接続が必要です。
3. Minecraft フォルダーを尋ねられたら、標準の `.minecraft` を使う場合は Enter を押します。別のランチャーを使う場合は、そのゲームフォルダーを入力します。既存の設定があれば、変更前のコピーを同じ `config` フォルダーへ保存し、接続先をローカルへ切り替えます。

## Minecraft を遊ぶとき

1. `2-Start-Local-Translator.bat` を実行します。
2. 「ready」と表示された黒い画面を開いたまま、Minecraft を起動します。
3. 終了時はサーバー画面で Ctrl+C を押します。

翻訳サービスは CPU のみを使用し、同時処理数と各推論スレッドを1に制限し、Windows の優先度を「通常以下」にします。GPU は使用しないため、3070 は Minecraft と影 MOD に使えます。負荷を抑える設定なので翻訳の応答は多少ゆっくりになることがあります。

英日モデルと Python 部品は初回に取得後、キャッシュされます。通常の翻訳時に外部 API へ通信しません。設定 API は `http://127.0.0.1:8765/translate`、状態確認は `http://127.0.0.1:8765/health` です。

この簡易 API はローカル PC 内だけにバインドされ、翻訳本文をコンソールやログへ記録しません。翻訳処理に失敗した場合、Kotoba Client は原文を表示します。
